德州扑克线上资格赛系统源码

本专题聚焦“线上发现赛事、参加资格入口、获得参赛权益，再衔接线下比赛”的产品路径。这是本仓库与普通私人局、俱乐部大厅或单纯 MTT 规则引擎最明显的区别。

资格赛玩家流程

发现赛事

玩家从赛事首页或线上赛事列表查看活动入口、时间和可参与项目。

进入资格路径

选择目标项目，查看报名条件、资格要求和对应参赛权益。

衔接线下活动

取得资格后进入报名或权益兑换，并由比赛房间和成员接口维护赛事状态。

项目中可核验的能力

赛事入口界面

Screenshots/0线上赛事.jpg 展示线上赛事列表和入口结构，适合承接卫星赛或资格赛项目。

用户与大厅服务

HallServantImp.h 和 UserInfoProcessor.* 提供用户、账户、道具及大厅请求相关代码结构。

比赛房间

RoomProcessor.* 与 RoomProto.tars 包含房间创建、查询、更新和成员操作接口。

客户端资源

仓库存在 Unity AssetBundle 与 manifest 文件，可用于核对界面资源和客户端交付范围。

边界说明：截图和源码能证明资格赛入口、房间和用户结构，但线下签到、座位编排、支付或完整运营后台是否包含，仍须按实际交付清单核验。
