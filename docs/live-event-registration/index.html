用户资料

用户服务代码涉及资料、账户、地址、道具和备注等结构，具体报名字段应以实际版本为准。

参赛成员

比赛房间协议和处理代码包含成员信息与更新接口，可作为报名后赛事状态管理的服务端基础。

现场衔接

页面定位于报名和现场比赛的连接；签到、座位和赛程后台是否完整交付需单独确认。

报名流程

选择项目

从赛事首页或资格赛列表进入目标现场活动。

核对条件

查看时间、资格、参赛权益和报名状态等信息。

进入赛事

报名结果与房间成员状态结合，再衔接现场签到与执行。
