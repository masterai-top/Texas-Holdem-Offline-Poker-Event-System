C++ · TARS · MATCH ROOM

德州扑克比赛房间服务源码

这一专题解释报名之后由哪些公开代码承接比赛流程：C++ 大厅服务处理请求，Tars 协议描述比赛房间与成员结构，数据访问层连接 MySQL 和 Tars 数据代理。

查看代码仓库

服务端代码地图

HallServer.*

大厅服务启动、配置加载和服务生命周期相关入口。

HallServantImp.h

用户、账户、比赛房间等大厅请求接口。

RoomProcessor.*

比赛房间创建、更新、列表查询、成员更新和删除等数据操作。

RoomProto.tars

比赛房间、参赛成员及相关请求/响应结构定义。

UserInfoProcessor.*

用户资料与相关业务数据的处理结构。

game*.cpp / sitdown.cpp

牌桌开始、参数、活动和入座相关的游戏逻辑入口。

技术栈与构建边界

层级 仓库可确认内容
服务端 C++ 大厅、用户、比赛房间与游戏逻辑接口
RPC/协议 Tars 服务和 `.tars` 协议定义
序列化 Protobuf 依赖与生成头文件引用
数据 MySQL 客户端与 Tars 数据代理接口
客户端 Unity AssetBundle 及 manifest 资源
构建 Linux Makefile，需补齐外部公共协议、库和环境路径

仓库不是 Node.js 项目，也不是开箱即用的完整部署包。编译前应审计 Tars、Protobuf、MySQL、内部公共模块及 Makefile 路径。
