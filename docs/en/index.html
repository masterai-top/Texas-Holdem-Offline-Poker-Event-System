Product overview

This is more than a generic poker-table sample. It documents the journey from discovering an online qualifier to registering for an offline poker event, while exposing C++ services for match rooms, participants and lobby requests.

Online qualifiers

Event home and listings provide tournament discovery and qualification entry points.

Registration and tickets

Detail and exchange screens present the path to live-event eligibility.

Match-room services

Create, update and query rooms while maintaining participant state.

Event journey

Discover

Sign in and browse qualifiers or the target live event.

Register

Review conditions, then register or exchange an eligible benefit.

Compete

Maintain room and participant state, then connect to verified on-site operations.

Technical structure

Layer Verifiable repository content
Server C++ lobby, user, match-room and game-logic hooks
Contracts Tars services and Protobuf references
Data MySQL client and data-proxy interfaces
Client assets Unity AssetBundles and manifests

This is not a Node.js project. The old npm quick start was inaccurate. Building requires compatible Tars, Protobuf, MySQL and external common modules referenced by the Makefile.
