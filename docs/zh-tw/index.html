德州撲克線下賽事管理系統

以賽事入口、報名、門票權益和比賽房間，銜接線上資格賽與現場活動。

查看產品畫面查看 GitHub

產品介紹

專案圍繞「發現賽事—參加資格賽—報名或兌換權益—進入比賽—銜接現場流程」組織入口，並包含比賽房間、成員和使用者服務的 C++ 程式碼。

線上資格賽

首頁與賽事列表提供活動和資格入口。

報名與門票

報名詳情、參賽條件和權益兌換畫面。

比賽房間

房間建立、更新、查詢和成員狀態介面。

賽事流程

發現

登入後瀏覽資格賽或目標現場活動。

報名

查看條件並報名或兌換參賽權益。

參賽

透過房間與成員介面維護狀態並銜接現場執行。

技術架構

層級可核驗內容
服務端C++ 大廳、使用者、比賽房間與遊戲邏輯
協議Tars 服務與 Protobuf 引用
資料MySQL 客戶端與資料代理
客戶端資源Unity AssetBundle 與 manifest

舊版 npm 啟動指令不適用。編譯前須準備相容的 Tars、Protobuf、MySQL 及外部公共模組。
