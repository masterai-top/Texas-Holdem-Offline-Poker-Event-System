## ✨ Unique Features


This project is a competitive Texas Hold’em system designed to **digitize offline tournaments**:


| Feature Module | Description |
| :--- | :--- |
| 🏆 **Tournament System** | Online tournament modes similar to CPG/TJPT; supports ticket qualifiers |
| 📊 **Offline Event Management** |
Offline tournament mode, player check-in, schedule management |
| 👥 **Club System** | Club creation, internal tournaments, ranking system |
| 🎫 **Ticketing System** | Online registration, ticket purchasing, integration with domestic events |
| 📈 **Points & Rankings** | Player points, leaderboards, season statistics |


## 🎯 Tournament Types


| Mode | Description |
| :--- | :--- |
| **Sit & Go** | Starts when full; quick-play format |
| **MTT** | Multi-Table Tournament; large-scale event |
| **Freezeout** | Freezeout format; no re-buys |
| **Ranking League** | Points-based league; seasonal rankings |
